# Seminario opencode · IESTP Churcampa

Material web de la presentación sobre **opencode** para estudiantes de educación superior del **IESTP Churcampa**.

Página creada como parte del seminario: muestra qué es opencode y 5 actividades prácticas para empezar a programar con la ayuda de un asistente de código en la terminal.

## Las 5 actividades

| #  | Actividad                                   | Objetivo                                        |
|----|---------------------------------------------|-------------------------------------------------|
| 01 | Mi primera página web                       | Crear un portafolio personal con HTML, CSS y JS |
| 02 | Resolver ejercicios de programación         | Algoritmos en Python con explicación línea a línea |
| 03 | Explicar y documentar código                | Entender y documentar cualquier código fuente   |
| 04 | Probar y corregir errores                   | Encontrar bugs y escribir pruebas automáticas   |
| 05 | Proyecto integrador: gestor de tareas       | Construir una aplicación completa de inicio a fin |

## Comandos básicos

```bash
# Iniciar opencode en tu proyecto
opencode

# Pedir una tarea en lenguaje natural
opencode "crea index.html con HTML básico"

# Explicar un archivo
opencode "explica qué hace este archivo paso a paso"
```

## Cómo usar

1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador.
3. Navega por las 5 actividades y copia los prompts de ejemplo.
4. Practica cada actividad con opencode en tu propia terminal.
