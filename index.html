Introducción

¿Qué es opencode?

opencode es un asistente de inteligencia artificial que trabaja dentro de tu terminal. Conversas con él en lenguaje natural y él crea, lee, modifica y ejecuta tu código, directamente en tu proyecto.

💬

Conversación natural

Le pides algo con tus palabras y él lo transforma en código funcional.

📁

Entiende tu proyecto

Lee la estructura real de tus archivos y propone cambios coherentes.

▶️

Ejecuta lo necesario

Instala dependencias, corre tu programa e incluso ejecuta pruebas.

🔒

Tú tienes el control

Tú decides qué aceptar y qué descartar. Aprende revisando cada cambio.

Práctica guiada

Las 5 actividades

Cada actividad es cada vez más desafiante. Haz clic en el botón ➜ para ver los comandos y pasos.

01

Mi primera página web

Crea un portafolio personal (sobre ti, tus estudios y tus intereses) con HTML, CSS y JavaScript desde cero.

02

Resolver ejercicios de programación

Pide a opencode resolver algoritmos en Python (condicionales, ciclos, funciones) y que te explique cómo funciona cada línea.

03

Explicar y documentar código

Pega un código (tuyo o de un ejemplo) y pide que lo explique paso a paso y lo documente con comentarios claros.

04

Probar y corregir errores

Introduce un programa con errores (bugs) y deja que opencode los encuentre, los explique y escriba pruebas para verificarlos.

05

Proyecto integrador: gestor de tareas

Construye una aplicación completa (lista de tareas con guardado en el navegador) desde la idea hasta el resultado final.

Referencia rápida

Comandos que usarás hoy

Copia cada comando con un clic para usarlo en tu terminal.

# Iniciar una sesión con opencode en tu proyecto
opencode

# Pedir que cree un archivo nuevo
opencode "crea index.html con HTML básico"

# Explicar el código de un archivo
opencode "explica qué hace este archivo paso a paso"
# Iniciar un repositorio en la carpeta actual
git init

# Ver los cambios pendientes
git status

# Guardar una versión del proyecto
git add .
git commit -m "Mi primer proyecto"

# Subir a GitHub
git push -u origin main
